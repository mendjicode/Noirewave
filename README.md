# NOIRWAVE - демонстрационный сайт продюсера

Полностью статический сайт-портфолио на HTML, CSS и JavaScript. Не требует Node.js, сервера или API-ключей.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в Chrome, Firefox или Edge.
3. Нажмите `Слушать биты`, затем кнопку Play на любой карточке.

Для локального сервера (по желанию) откройте папку проекта в терминале:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000 .

## Функции

- Адаптивная верстка для телефона, планшета и ПК.
- Каталог из 6 демо-битов с фильтрами Trap / Ambient / R&B.
- Реальное звуковое демо, синтезируемое на устройстве через Web Audio API (не аудиофайлы и не внешние треки).
- Пауза, переключение и закрытие плеера.
- Модальное окно для составления и копирования заявки.
- Блок лицензий, информация о продюсере, навигация и мобильное меню.

## Важно

Это **демонстрационный проект**, а не реальный магазин. NOIRWAVE - вымышленный бренд. Названия треков, цены и лицензии - примеры. Звуковые петли сгенерированы программно и не заявляются как полноценные студийные биты. Кнопка заявки копирует текст, а не отправляет сообщение реальному продавцу. Реальную контактную ссылку или оплату нужно подключать отдельно. Для коммерческого сайта условия лицензий необходимо юридически уточнить.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий GitHub.
2. Загрузите в корень репозитория три файла: `index.html`, `styles.css`, `script.js`.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите `Deploy from a branch`, ветка `main`, папка `/ (root)`, затем Save.
5. После публикации GitHub покажет URL сайта.

## Используемые ресурсы

- Шрифты Manrope и DM Sans через Google Fonts. При отсутствии интернета используются системные шрифты.
- Все графические обложки и декоративные элементы созданы CSS без внешних изображений.
- Аудио генерируется в браузере без загрузки сторонних музыкальных записей.
